# Frontend MVP «СПОРИМ»

Реализована первая задача этапа MVP

- каталог событий
- поиск по названию и описанию
- фильтр по категориям
- переключатель «Только активные»
- карточки открытых, ожидающих результат и завершённых событий
- отдельная страница события
- состояния загрузки, пустого результата и ошибки
- адаптивная вёрстка

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска открыть `http://localhost:5173`

Сейчас приложение использует тестовые данные из `src/data/mockEvents.ts`

## Подключение к бэкенду

Создать файл `.env.local`

```env
VITE_API_BASE_URL=http://localhost:5000
VITE_USE_MOCK_API=false
```

Клиент отправляет запросы

- `GET /api/v1/events`
- `GET /api/v1/events/{eventId}`

Форматы данных описаны в `src/types.ts` и соответствуют переданному OpenAPI-контракту MVP

## Проверка production-сборки

```bash
npm run build
npm run preview
```
